# 科研知识库，从这里开始

标签： #type/MOC #status/进行中

这是一个可自由调整的起步库。先读约定，再用真实材料替换示例；包内三篇演示记录均为虚构占位，不表示任何真实研究。

1. 阅读 [[知识库约定]]，理解目录、标签、MOC 与证据链。
2. 阅读 [[09_Templates/模板使用说明]]，启用核心模板并设置目录。
3. 查看 [[04_Research/示例课题/00_课题主页|示例课题主页]]，了解问题、数据与实验如何连接。
4. 打开 [[07_Thesis/00_论文工作台|论文工作台]]，先规划论断和证据，再写章节。
5. 查看 [[06_Knowledge/研究方法/0_MOC - 研究方法|研究方法 MOC]]，理解主题地图如何组织路径。

## 每周只做几件关键事

- 处理会影响当前任务的收集箱材料，保留来源。
- 把有用的阅读理解提炼成可复用知识，链接理由写清楚。
- 补齐本周实验的版本、参数、原始结果和失败记录。
- 更新论文证据缺口，安排下一步验证。
- 备份变更，检查链接与敏感信息。
