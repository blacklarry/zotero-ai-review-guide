# 模板使用说明

标签： #type/说明

在 Obsidian 启用核心“模板”插件，将模板文件夹设为 `09_Templates`。先在目标目录新建并命名笔记，再通过命令面板插入模板；不要直接修改模板原件来写实际记录。

| 模板 | 目标位置 |
| --- | --- |
| [[09_Templates/阅读笔记模板]] | 03_Literature |
| [[09_Templates/知识笔记模板]] | 06_Knowledge/主题 |
| [[09_Templates/研究问题模板]] | 04_Research/课题/01_研究问题 |
| [[09_Templates/数据集档案模板]] | 04_Research/课题/02_数据集 |
| [[09_Templates/实验记录模板]] | 04_Research/课题/03_实验记录 |
| [[09_Templates/项目主页模板]] | 05_Projects/项目 |
| [[09_Templates/论文章节模板]] | 07_Thesis |
| [[09_Templates/MOC模板]] | 对应主题目录，文件名0_MOC - 主题名 |
| [[09_Templates/课程笔记模板]] | 02_Courses/学期/课程 |

只有 `{{title}}` 和 `{{date:YYYY-MM-DD}}` 自动替换；其余字段手填。日期变量是插入当天的日期，`updated` 不会持续自动更新。`publication_date` 是来源发表日期，未知保留“待核验”。YAML 属性保持标量，状态和正文标签保持一致；链接必须填入真实存在的笔记，不能生成空链接。

使用示例与约定见 [[00_开始这里]]、[[知识库约定]]。
