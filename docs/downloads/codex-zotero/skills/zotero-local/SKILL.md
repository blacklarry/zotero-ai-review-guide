# Zotero 本地文献检索

依赖已配置并连接的 `zotero-fulltext` MCP。处理用户要求的本地文献库读取；这五个工具不提供联网论文搜索或文献库写入。

## 工具发现与连接

- 发现当前会话可用的 Zotero MCP 工具，遵循实际工具名称与参数定义；Codex 可能添加服务前缀，不硬编码其他平台的名称。
- 首次使用先调用 `collections`。成功返回分类或有效的空分类列表都可验证接口；工具缺失或连接错误不能解释为检索无命中。
- 如工具不可用，报告具体限制，提示检查 MCP 运行环境、Zotero 本地 API 与 Codex 重启后的工具发现；不声称已读取文献库。

## 工具选择

| 工具短名 | 用法 |
| --- | --- |
| `collections` | 列出当前库分类，验证只读连接。 |
| `search` | 用 `query` 检索元数据及已索引文字；按实际定义使用 `collection`、`tag`、`limit`。 |
| `lookup` | 用准确 `citekey` 核对一条文献。 |
| `fulltext` | 按用户请求读取 `citekey` 的编号段落，用 `offset`、`limit` 分页。 |
| `fulltext_search` | 在指定 `citekey` 中查 `query`，用 `before`、`after` 获取附近段落。 |

主题、题名或作者请求先用 `search` 定位；用户提供引用键时先 `lookup`。`citekey` 与 Zotero 条目 key 不同，只使用实际返回的引用键，不用题名或 DOI 代替。存在相似结果时列出候选及区别，先确认目标。

## 证据与结果

- 文献结果列出实际返回的题名、作者、年份、引用键、条目 key，以及 DOI 或来源链接；缺失字段标记未提供。
- 没有命中时如实说明本地库未找到匹配项；不虚构论文、引用键或未执行的工具调用。
- 仅在用户要求阅读、摘要或文内证据时请求全文。查局部内容优先用 `fulltext_search`；需要完整阅读时按返回的 `next_offset` 继续，不推算偏移。
- 全文结果截断、附件未索引或正文不可用时说明已读取范围；不能据此认定论文未讨论该问题。
- 摘录和结论附引用键、工具返回的段落定位与必要上下文。段落编号不是 PDF 页码；数值、条件与局限需要回到原文核对。
- 将推断与论文原文区分，按用户请求停止在足够的证据范围内。
