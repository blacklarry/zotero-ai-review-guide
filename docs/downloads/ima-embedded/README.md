# ima 嵌入式系统学习示例资料

整理日期：2026-10-29。

本包提供 3 份 STM32 原创 Markdown 学习资料，供演示主题归档、知识库问答和来源回查。资料不是厂商手册，也不是已经完成的实验报告；未连接开发板，未运行固件，没有真实串口日志、波形或性能数据。

## 三个分类

- RK3588：保留分类，本例不补资料。
- STM32：3 份学习材料，依次是最小工程、GPIO/按键/LED、UART 与调试记录。
- FPGA：保留分类，本例不补资料。

三份 STM32 资料末尾均附有 ST 官方来源链接。芯片型号、板卡版本、引脚、时钟及测试结果需要依据自己的实际工程填写，未知处保持待核对。

## 用于 ima

1. 解压本包，在新建的示例知识库中按 RK3588、STM32、FPGA 归类。
2. 添加文件后，回到目标知识库检查标题、正文与处理状态。Markdown 若先进入笔记区，需进一步确认是否已归到目标库。
3. 先选 STM32 三份资料，要求 AI 仅依据这些内容整理学习顺序并给出来源；逐项打开来源复核。
4. 将自己的学习记录与原始资料分开保存，注明日期、来源及未验证事项，不把建议写成已完成测试。
