# Zotero 本地文献检索

用于用户要求连接 Zotero、查找已收藏文献、按引用键定位条目或读取文献全文的任务。
依赖 WorkBuddy 已连接的 `zotero-fulltext` MCP 服务；本技能包不携带用户文献库数据。
能力限于本地库的读取与检索，不提供联网寻找新论文或写入 Zotero 文献库的操作。

## 连接与工具发现

1. 从 WorkBuddy 当前可用 MCP 工具中发现 Zotero 工具，使用其实际名称与参数定义。
2. 下文使用工具短名；平台可能添加服务前缀，不要硬编码其他平台的工具前缀。
3. 每次新连接先调用 `collections` 验证服务是否可用，空分类列表也可能是有效结果。
4. 连接失败时报告实际错误，说明需检查 Zotero 是否运行、MCP 服务配置及本地连接。
5. 工具未出现或连接失败时，不把错误解释为文献库没有命中。

## 选择检索工具

| 工具短名 | 用途与参数 |
| --- | --- |
| `collections` | 列出当前库分类，并检查连接。 |
| `search` | 按 `query` 检索元数据及索引全文；可用 `collection`、`tag`、`limit` 缩小范围。 |
| `lookup` | 已知准确引用键时优先调用，参数为 `citekey`。 |
| `fulltext` | 按请求读取指定 `citekey` 的编号段落；使用 `offset`、`limit` 分页。 |
| `fulltext_search` | 按请求在指定 `citekey` 全文内查 `query`；用 `before`、`after` 返回相邻段落。 |

`citekey` 是引用键，必须是无空格的单个标识；它与 Zotero 条目 key 不同。
不要把标题、DOI、条目 key 或作者年份拼接文字当作 `citekey`。
用户给出引用键时先 `lookup`；给出主题、标题或作者时用 `search` 查找，再使用返回的引用键。
分类和标签过滤值应依据实际返回内容及工具定义，不猜测分类标识。

## 检索与全文读取

- 用用户提供的关键词开始检索；需要放宽范围时说明所用关键词或过滤条件。
- 存在多个相似结果时列出候选及区别，依据标题、作者、年份、DOI 定位目标。
- 无命中时如实说明“本地 Zotero 文献库未找到匹配项”，不虚构条目或引用键。
- `search` 可匹配索引全文；只有用户要求正文、阅读、摘要或文内证据时才调用全文工具。
- 阅读整篇或指定段落用 `fulltext`；查术语、方法、结果或证据位置用 `fulltext_search`。
- 全文未索引或不可用时说明这一限制；不能据此断言论文没有相关内容。
- 返回结果截断或 `paging` 显示后续内容时，用返回的 `next_offset` 继续分页，不自行推算偏移。
- 若当前工具没有分页参数，报告已返回范围及截断状态，必要时缩小检索条件；不声称结果完整。
- 用户只需要局部证据时，在获得足够上下文后停止读取，避免将片段描述为全文结论。

## 结果与证据输出

- 文献结果列出作者、年份、标题、引用键及条目 key；仅输出工具实际提供的字段。
- 同时列出返回的 DOI 或来源链接；字段缺失时标注未提供，不补造元数据。
- 正文摘录与摘要注明文献引用键及工具返回的 paragraph locator，保留可追溯的段落定位。
- 段落序号不是 PDF 页码；只有工具明确返回页码时才使用页码定位。
- 区分元数据命中、全文命中和已读取正文，说明筛选范围或尚未读取的内容。
- 依据实际检索内容回答；遇到缺失、截断或冲突时明确说明，避免把推断当作文献原文。
